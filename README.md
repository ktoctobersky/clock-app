# じかんのべんきょう そうごうどけい

小学校低学年向けに、**アナログ時計**と**デジタル時計**を使って時間を学べるシンプルなWebアプリです。  
iPadなどのタブレットでのタッチ操作に最適化されています。

---

## 主な機能

- **アナログとデジタルの連動**
  - アナログ：短針・長針をドラッグで動かす（操作中は針と範囲が色で強調表示）
  - デジタル：スロットのスクロール、＋/−ボタン、直接入力で時間を変更
  - 「じっこう」ボタンでデジタルの時刻をアナログに反映

- **操作範囲の色分け**
  - 文字盤に**ピンク（内側）＝短針（じ）**  
  - **みずいろ（外側）＝長針（ふん）**  
  - 常時表示され、ドラッグ中はさらに濃く表示

- **表示切替**
  - 12時間表記／24時間表記を切替可能

- **音声読み上げ**
  - 「▶︎ よみあげ」ボタンで現在時刻を読み上げ
  - 声の種類は端末にある日本語音声から選択可能

- **クイズ（もんだいモード）**
  - **かんたん**：12時間・5分刻み（AM/PMは無視）
  - **ふつう**：12時間・1分刻み（AM/PMは無視）
  - **ちゃれんじ**：24時間・1分刻み（AM/PMも判定）
  - 出題 → アナログを操作 → 「こたえる」で正誤判定
  - 正解なら「ピンポーン」、不正解なら「ブブー」と効果音
  - 「もんだいを おわる」で成績（正解数／出題数／正答率）を表示し、通常モードへ戻る

---

## つかいかた

1. `index.html` をブラウザで開く、もしくはGitHub Pagesからアプリを開くとそのURLで遊べます
2. アナログの針をドラッグするか、デジタルのスロットや入力欄で時間を操作
3. 「じっこう」でデジタル→アナログを同期
4. クイズモードでは「れべる」を選んで「しゅつだい」→針を合わせて「こたえる」  
   終了は「もんだいを おわる」で成績を確認

---

## ヒント

- 初回の音声再生はボタン操作が必要です（ブラウザの制限のため）  
- iPadの「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語」で  
  好みの音声を追加すると選べるようになります

---

## 公開方法

- **GitHub Pages** や **Netlify** にそのまま `index.html` を置けば動作します
- 配布時はURLを**QRコード化**すると子どもがアクセスしやすく便利です
